# Lebanese E-Commerce Gateway Core 🇱🇧

## Overview
An open-source Node.js wrapper designed specifically for the Lebanese developer ecosystem. Due to the ongoing economic crisis and the shift towards digital local payment solutions (like Whish Money), small businesses struggle to integrate complex APIs into their web control panels. This core library standardizes cryptographic signatures, error handling, and transaction initialization for local payment nodes.

## Why this exists?
Many global payment gateways are restricted or non-functional in our region. Local businesses rely on fragmented, undocumented local APIs. This package provides a secure, structured, and developer-friendly bridge to keep the local digital economy moving.

## Features
- **Cryptographic Request Signing:** Built-in SHA-256 HMAC generation.
- **Environment Management:** Seamless switching between Sandbox and Production.
- **Error Normalization:** Standardized error catching for robust backend integration.

*Currently maintained as part of a university-driven initiative to support local retail tech infrastructure.*
